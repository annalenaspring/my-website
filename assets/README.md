# Assets — was noch fehlt

Diese Dateien fehlen aktuell und sollten von dir ergänzt werden (einfach an den genannten Pfaden im Repo ablegen, dann werden sie automatisch eingebunden):

- `assets/img/portrait.jpg` — ein Foto von dir für die "Über mich"-Sektion (Hochformat, mind. 1200×1500px)
- `assets/img/character.svg` (optional) — falls du eine echte Leitfigur/Illustration hast, kann sie das aktuelle Platzhalter-SVG in `index.html` (`#leitfigur`) ersetzen
- `assets/img/work/*.jpg` (optional) — Standbilder/Stills zu deinen Filmen, aktuell sind Farbflächen als Platzhalter im Work-Bereich

Nichts davon ist zwingend für die erste Vorschau — die Seite funktioniert auch ohne, zeigt dann aber Platzhalter.
